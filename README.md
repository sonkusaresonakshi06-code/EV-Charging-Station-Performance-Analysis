# EV Charging Station Performance Analysis | Power BI

## 1. ⚡ Project Overview

The **EV Charging Station Performance Analysis** is an interactive Power BI dashboard created to analyse electric vehicle charging station performance and identify important patterns across different operational and demand-related factors.

The dashboard provides insights into **station utilization, charging sessions, charger types, port availability, station status, waiting time, session duration, pricing, power output, traffic conditions and time-based charging demand**.

---

## 2. 🎯 Project Objective

The main objective of this project is to analyse EV charging station data and identify key operational, demand and performance patterns.

This dashboard helps to:

- Analyse overall charging station utilization
- Compare charging sessions across charger types
- Monitor available, occupied and out-of-service ports
- Compare station-level performance
- Analyse charging demand during different hours
- Compare peak and non-peak charging activity
- Analyse average session duration
- Compare pricing types
- Analyse average charging power output
- Monitor traffic congestion around charging stations
- Identify areas for improving station performance

## 5. 📈 Dashboard Analysis

### 5.1 Executive Overview

The Executive Overview provides a high-level view of overall EV charging station performance.

The dashboard analyses:

- Station-wise utilization
- Charging sessions by charger type
- Utilization by location type
- Station status distribution
- Average waiting time by station

This page provides a quick understanding of overall station performance and charging activity.

---

### 5.2 Station Performance & Charging Analysis

This page focuses on station-level performance and charging infrastructure.

The dashboard compares:

- Station-wise utilization
- Available ports by station
- Available vs occupied ports
- Out-of-service ports
- Station capacity and availability

This analysis helps identify differences in station utilization and port availability.

---

### 5.3 Time & Demand Analysis

The Time & Demand Analysis page focuses on charging demand across different time periods.

The dashboard analyses:

- Total charging sessions
- Average session duration
- Peak vs non-peak sessions
- Average utilization by hour
- Average waiting time by charger type
- Average session duration by location type

The hourly utilization analysis helps understand how station utilization changes throughout the day.

---

### 5.4 Pricing Analysis

The Pricing Analysis page focuses on charging pricing and related operational factors.

The dashboard analyses:

- Charging sessions by pricing type
- Average charging price
- Average power output
- Average traffic congestion

This page helps compare charging activity across different pricing types and provides additional operational context through power output and traffic conditions.

---

### 5.5 Recommendations & Key Insights

The final dashboard page summarizes important findings and provides practical recommendations.

### ⚡ Improve High-Demand Stations

Monitor highly utilized stations and consider increasing charging capacity where required.

### 🔌 Optimize Port Availability

Maintain sufficient available ports at busy stations to improve customer experience.

### 💰 Review Pricing Strategy

Compare pricing types and network-wise pricing to maintain competitive charging costs.

### 🚗 Monitor Traffic Conditions

Use traffic patterns to understand demand and improve station planning during busy periods.

### 🎯 Overall Goal

Improve station utilization, reduce customer waiting, optimize pricing and enhance the overall EV charging experience.
